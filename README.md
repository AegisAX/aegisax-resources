# AegisAX 디자인 자료실

홈페이지·PPT·IT·정보보안에 사용할 무료 아이콘, 사진, 일러스트, 배경·패턴, 3D 자료 사이트 32곳을 비교하는 정적 웹사이트입니다.

## 주요 기능

- 자료 유형·용도·디자인 스타일·다운로드 형식·일괄 다운로드·라이선스·무료 범위별 필터
- 키워드 검색, 카드 보기와 전체 비교표
- 최대 3개 사이트 나란히 비교
- 브라우저별 즐겨찾기
- 공식 다운로드 페이지와 라이선스 원문 링크
- 데스크톱·모바일 반응형 화면

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 웹페이지 구조와 이용 가이드 |
| `styles.css` | 반응형 디자인 |
| `app.js` | 검색·필터·비교·즐겨찾기 |
| `resources.json` | 32개 사이트의 비교 데이터·공식 출처 |
| `favicon.svg` | 사이트 아이콘 |
| `.nojekyll` | GitHub Pages에서 정적 파일을 그대로 제공 |
| `DEPLOY.md` | GitHub 업로드 및 Pages 게시 방법 |

## 로컬 실행

이 폴더에서 다음을 실행하고 `http://localhost:8000/`을 엽니다.

```bash
python3 -m http.server 8000
```

Windows에서는 `py -m http.server 8000`을 사용할 수 있습니다. JSON 데이터를 읽으므로 `index.html`을 더블클릭하는 대신 HTTP 서버로 확인합니다. 빌드나 패키지 설치, API 키, 데이터베이스는 필요하지 않습니다.

## 데이터 수정

`resources.json`에서 사이트 설명과 공식 링크, 형식, 라이선스를 수정합니다. 새 항목은 기존 필드 구조와 고유한 `id`를 사용하고, 공식 출처를 확인한 날짜를 `sourceDate`에 기록합니다. 검색·필터 목록과 자료 수는 데이터에서 생성됩니다.

화면 상단과 비교표의 확인일, 소개 문구의 사이트 수는 HTML/JS에 함께 표시되므로 전체 검토 후 해당 문구도 수정합니다. 현재 데이터 확인일은 2026-11-24입니다.

## 접근 범위와 즐겨찾기

이 코드에는 로그인이나 사용자별 접근 제어가 없습니다. 기존 Sites 서비스의 접근 제어는 함께 복사되지 않습니다. 저장소 비공개 여부와 GitHub Pages 웹사이트 공개 여부는 별개입니다. 게시 전 `DEPLOY.md`를 확인하세요.

즐겨찾기는 방문 브라우저의 localStorage에 저장됩니다. 서버로 전송하거나 기기 간 동기화하지 않습니다. Sites에서 저장한 즐겨찾기는 주소가 바뀌는 GitHub Pages로 자동 이전되지 않습니다.

## 자료의 이용 조건

이 저장소는 디자인 자료의 공식 사이트와 이용 조건을 안내하는 디렉터리입니다. 해당 서비스의 아이콘·사진 원본을 재배포하지 않습니다. 다운로드한 자료에는 각 원출처의 라이선스가 적용됩니다. 무료·유료 혼합 및 자료별 조건을 확인하세요.

## 게시

GitHub 저장소 루트에 이 폴더 안의 파일을 올린 뒤, Pages의 게시 원본을 `main` 브랜치의 `/ (root)`로 지정합니다. 자세한 절차와 공개 조건은 [DEPLOY.md](DEPLOY.md)를 참고하세요.
